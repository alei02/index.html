LICOR DE MUÑA

LICOR MUÑA.

Licores Gallegos


El licor de muña es una bebida tradicional andina que se elabora a partir de las hojas de la planta de muña. Este licor se utiliza para combatir el mal de altura y problemas digestivos, gracias a sus propiedades naturales. Se elabora mediante un proceso de maceración en aguardiente de uva, lo que le otorga un delicioso sabor y beneficios para la salud.
